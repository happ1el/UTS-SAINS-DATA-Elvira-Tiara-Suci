# Sistem Rekomendasi KNN - RetailRocket

## Deskripsi
Proyek ini merupakan implementasi sistem rekomendasi menggunakan
algoritma K-Nearest Neighbors (KNN) pada dataset RetailRocket.

## Metode
- Algoritma: K-Nearest Neighbors (KNN)
- Similarity: Cosine Similarity
- Jumlah tetangga: 5
- Jumlah rekomendasi: 3 item

## Dataset
Dataset yang digunakan adalah RetailRocket, yang berisi interaksi
pengguna terhadap item.

## Teknologi
- Python
- NumPy
- Pandas
- Scikit-learn
- SciPy

## Cara Menjalankan
1. Instal Python.
2. Instal library yang dibutuhkan:
   pip install numpy pandas scikit-learn scipy
3. Buka notebook atau jalankan script Python proyek ini.
4. Pastikan dataset tersedia sesuai path yang digunakan dalam kode.

## Hasil
Program memilih user secara reproducible menggunakan random seed,
mencari 5 tetangga terdekat, dan menghasilkan 3 rekomendasi item.
